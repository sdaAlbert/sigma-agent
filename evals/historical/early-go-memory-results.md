- **Observation:** directly recorded in a run or evaluator output.
- **Mechanism verified:** a feature path worked, without evidence of task-quality benefit.
- **Incomplete/invalid:** do not treat as a completed score.
- **Interpretation:** a limit on what the result supports.

## Evidence location and retention

The `Local detail note` names refer to ignored files under `evals/results/`; those full-length notes are local and are not included in this Git branch. Detailed transcripts, patches, run metadata, and evaluator logs remain in the ignored `var/` benchmark data paths recorded by those notes. Keep them as local source evidence unless they are separately copied into the central archive. This committed table is the concise, shareable summary; it is not a substitute for raw evaluation artifacts.

## How this relates to the primary evaluation

These Go and memory experiments are historical design evidence. The active, externally comparable evaluation track is [SWE-bench Verified Mini](../swebench-verified-mini/README.md). Do not merge these early single-task or retrieval-only outcomes into its score.
