These are early, small Go-zero/Multi-SWE-Bench records. They mix issue-only,
hinted, guided, and evaluator-diagnostic runs, so do not combine them into one
success rate or compare them directly with the Mini SWE-bench results.

For the concise outcome matrix across Go, Skill, and memory experiments, see
the parent [early results table](../early-go-memory-results.md).

- [`issue-benchmark-inventory.md`](issue-benchmark-inventory.md): observed
  outcomes and assistance conditions.
- [`superseded-10-task-subset.md`](superseded-10-task-subset.md): a subset
  proposal that was never run.
- [`superseded-paired-evidence-set.md`](superseded-paired-evidence-set.md):
  historical evidence and a superseded comparison proposal.
- [`subset-naming-research.md`](subset-naming-research.md): terminology and
  benchmark-status guidance.
- [`scripts/prepare-go-benchmark-patches.ps1`](scripts/prepare-go-benchmark-patches.ps1):
  patch preservation and source-only diagnostic helper.
